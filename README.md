# Sans

Pygame 기반 멀티플레이 생존 전투 게임입니다.

## 실행

### 1. 의존성 설치

```powershell
python -m pip install -r requirements.txt
```

### 2. 서버 실행

프로젝트 폴더에서 먼저 서버를 실행합니다.

```powershell
python Server.py
```

### 3. 클라이언트 실행

새 터미널에서 클라이언트를 실행합니다.

```powershell
python TheTest.py
```

기본 서버 주소는 `127.0.0.1:5555`입니다. 주소와 포트는 `Config.py`에서 변경할 수 있습니다.

### 4. PyInstaller 빌드

PyInstaller를 설치한 뒤 프로젝트 폴더에서 빌드 스크립트를 실행합니다.

```powershell
python -m pip install pyinstaller
python build.py
```

클라이언트와 서버가 각각 `dist/SansClient`와 `dist/SansServer`에 생성되며, `Image`, `Font`, `Sound` 폴더가 자동으로 포함됩니다.

## 게임 모드

### 일반전

- 최소 2명이 모이면 대기실에서 3초 카운트다운 후 시작합니다.
- 게임이 시작된 뒤에는 새로운 플레이어가 참가할 수 없습니다.
- 마지막까지 살아남은 플레이어가 승리합니다.
- 자기장이 1분부터 축소되기 시작하며, 3분 후에는 맵 중앙의 작은 안전 구역만 남습니다.

### 연습모드

- 메인 화면의 `Practice` 버튼으로 입장합니다.
- 자기장과 자기장 피해가 비활성화됩니다.
- 플레이어 이미지와 같은 연습용 더미가 배치되며, 공격할 때 실제 헤드/몸통 히트박스로 피해를 시험할 수 있습니다.
- 더미 위 피해량 텍스트는 1.5초 동안 표시되고, 더미를 처치해도 연습 게임은 끝나지 않으며 잠시 후 부활합니다.
- `F10`으로 디버그 모드를 켜거나 끌 수 있습니다.
- 디버그 모드에서는 모든 스킬을 사용할 수 있습니다.
- 게임 중 `1~6`으로 무기를 바꿀 수 있습니다.

## 무기

현재 선택할 수 있는 무기는 다음과 같습니다.

1. 권총
2. 라이플
3. 샷건
4. 저격총
5. 기관단총
6. 칼

저격총은 `Image/Sniper.png`를 사용합니다. 총알은 발사 순간의 위치와 방향을 고정한 뒤 짧은 준비 시간 후 비행하므로, 이동 중 발사해도 시작점이 크게 흔들리지 않습니다.

## 스킬

- **달팽이 세개**: 밝은 시야 안에 폭탄을 설치합니다.
- **매의 눈**: 일정 시간 고정 반경의 넓은 원형 시야를 얻습니다.
- **보호막**: 일정 시간 피해를 막습니다.
- **은신**: 1.5초 동안 적에게 완전히 보이지 않습니다. 재사용 대기시간은 30초입니다.
- **와드**: 원하는 위치에 최대 3개를 설치하며, 설치한 위치 주변의 고정 반경 시야를 밝힙니다. 벽 안에는 설치할 수 없습니다.
- **부활의 차**: 인벤토리에서 퀵슬롯에 장착해야 합니다. 장착한 상태로 사망하면 체력의 절반으로 한 번 자동 부활하고 인벤토리와 퀵슬롯에서 사라집니다. 슬롯 키를 직접 누르는 액티브 스킬은 아닙니다.
- **텔포**: 텔포 석상을 설치하고 해당 위치로 이동합니다.
- **기절탄**: 흰색 탄환을 발사하며, 적중한 플레이어를 2.5초 동안 기절시킵니다.

게임 화면 오른쪽 위에 전체 맵을 표시하는 미니맵이 나타납니다. 미니맵에는 플레이어 위치를 표시하지 않습니다.

기절탄 아이콘은 `Image/Stun_Icon.png`를 사용합니다.

## 맵과 상호작용

- 집, 문, 보물상자, 덤불, 발광 룬, 가구, 돌 오브젝트가 맵에 생성됩니다.
- 보물상자에 닿으면 스킬 또는 탄창 회복 보상을 얻습니다.
- 총알로 보물상자를 파괴해도 보상을 얻을 수 있습니다.
- 보급품 상자는 낙하 전조 광선과 맥동 표시 후 생성되며, 접근하면 회복 또는 버프를 제공합니다.
- 맵 중앙에는 물웅덩이가 생성됩니다.
- 물웅덩이를 밟으면 이동 속도가 일시적으로 감소합니다.
- 덤불에서는 은신 효과가 적용됩니다.
- 와드는 설치자에게만 설치 위치 주변의 시야를 제공하며, 설치 위치는 다른 플레이어가 볼 수 있는 경우 화면에 표시됩니다.
- 발광 룬을 밟으면 주변 플레이어에게 약 2초 동안 룬 위치 신호가 표시됩니다.
- 발광 룬은 룬 타일의 동서남북 한 칸 안에 들어가도 밟은 것으로 판정합니다.
- 집 내부에는 침대와 의자 가구가 배치되며, 가구는 시야를 가리고 총알에 파괴될 때 파티클을 생성합니다.
- 돌 오브젝트는 시야를 가리고 총알을 맞으면 총알의 진행 방향을 반사합니다.
- 보급품은 체력 회복, 이동 속도 증가, 보호막만 제공합니다. 스킬은 제공하지 않습니다.
- 부활의 차가 퀵슬롯에 장착된 플레이어가 사망하면 부활이 처리될 때까지 승리 판정을 보류합니다.
- 자기장 바깥에 3초 이상 머무르면 피해가 시작되고 시간이 지날수록 피해량이 증가합니다.

## 전투 시스템

- 플레이어 히트박스는 머리와 몸통으로 나뉩니다.
- 머리와 몸통은 `F9`로 화면에 표시할 수 있습니다.
- 머리 피격에는 헤드샷 피해 배율이 적용됩니다.
- HP, 피해, 스턴, 승리 판정은 멀티플레이 서버 상태를 기준으로 처리됩니다.
- 스턴 중인 플레이어는 이동할 수 없고 화면에서 좌우로 흔들립니다.
